## Projects

**[RigRAG](https://github.com/djmgmz/RigRAG)** turns a request like *"70k gaming PC, 1440p, AMD CPU"* into a complete build, priced in pesos, where every part actually fits together. I didn't want a language model guessing whether a CPU works with a motherboard, so part selection, compatibility checks and pricing are regular Python against PostgreSQL, with tests. The model only reads the request and explains the finished build, citing hardware notes it pulls from Qdrant.<br>
<sub>Python · FastAPI · PostgreSQL · Qdrant · React + TypeScript · Docker</sub>

**[FullCourt](https://github.com/djmgmz/FullCourt)** is an NBA research assistant for questions a box score can't answer alone, like *"efficient scoring guards who can also run an offense"*. It mixes exact SQL stats with semantic search over player style descriptions, ranks the results, and has the LLM explain each pick. A grounding check then makes sure every explanation sticks to the evidence it was given.<br>
<sub>Python · FastAPI · SQLite · FAISS · sentence-transformers · React + TypeScript</sub>
