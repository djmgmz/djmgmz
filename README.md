## 📌 Featured Projects

### [🖥️ RigRAG](https://github.com/djmgmz/RigRAG)
RAG-powered PC build recommender. Plain-English requests like *"70k gaming PC, 1440p, AMD CPU"* become complete, compatible builds priced in pesos. Part selection, compatibility checks and pricing come from tested Python code backed by PostgreSQL. The LLM only parses the request and explains the build, citing sourced hardware notes retrieved through hybrid search in Qdrant.

`Python` `FastAPI` `PostgreSQL` `SQLAlchemy` `Alembic` `Qdrant` `Sentence Transformers` `Ollama` `Groq` `React` `TypeScript` `Vite` `Docker` `GitHub Actions` `pytest`

### [🏀 FullCourt](https://github.com/djmgmz/FullCourt)
NBA research assistant that answers questions like *"efficient scoring guards who can also run an offense"*. It combines exact SQL stats with semantic search over player style profiles in FAISS, blends the two into a ranked score, and has the LLM write explanations that a grounding check verifies against the evidence it was given.

`Python` `FastAPI` `Streamlit` `SQLite` `FAISS` `Sentence Transformers` `PyTorch` `pandas` `Beautiful Soup` `Gemini` `Ollama` `React` `TypeScript` `Vite` `pytest`
